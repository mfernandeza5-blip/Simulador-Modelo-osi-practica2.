# Simulador Interactivo del Modelo OSI - Práctica 2

## Comunicación de Datos

Este proyecto corresponde a la Práctica 2 de la asignatura Comunicación de Datos.

El proyecto consiste en el desarrollo de un simulador interactivo en Python para visualizar el proceso de encapsulamiento y desencapsulamiento de datos a través de las 7 capas del Modelo OSI.

## Objetivo

Desarrollar un simulador que permita representar de manera visual el recorrido de un mensaje desde PC-A hasta PC-B, mostrando el proceso de encapsulamiento, transmisión y desencapsulamiento.

## Funcionamiento

El simulador permite:

- Ingresar un mensaje desde PC-A.
- Iniciar la transmisión hacia PC-B.
- Visualizar las 7 capas del Modelo OSI.
- Mostrar el proceso de encapsulamiento.
- Mostrar la información agregada en cada capa.
- Simular la transmisión de los datos.
- Visualizar el proceso de desencapsulamiento.
- Comprobar la recuperación del mensaje original.
- Mostrar información de latencia y tamaño de los datos.

## Capas del Modelo OSI

1. Capa de Aplicación
2. Capa de Presentación
3. Capa de Sesión
4. Capa de Transporte
5. Capa de Red
6. Capa de Enlace de Datos
7. Capa Física

## Tecnologías utilizadas

- Python
- Tkinter
- Base64
- Modelo OSI

## Archivo principal

El código principal del proyecto se encuentra en:

`simulador_modelo_osi_practica2.py`

## Ejecución

Para ejecutar el simulador se necesita tener Python instalado.

Después se debe abrir el archivo:

`simulador_modelo_osi_practica2.py`

y ejecutarlo desde un entorno compatible con Python, como Visual Studio Code.
